Help & Documentation

Getting Started

This tool provides web and command line interfaces for running the remediation playbook analysis. It supports both single firewall operations and batch processing using CSV files.

Key Features: Remediation analysis and guidance for manual remediation, bulk TOTP reset for all users, and bulk password resets for all users.

The tool can automatically enable SonicOS API via SSH management failback. SonicOS API is auto-disabled after running the playbook.

Prerequisites & Requirements

Network Requirements

  • • Network connectivity to target firewalls
  • • HTTPS access to SonicOS API (typically port 443)
  • • SSH access for SSH failback (if needed)
  • • Verify firewall reachability before operations

System Requirements

  • • Modern web browser (Chrome, Firefox, Safari, Edge) if using the web interface
  • • JavaScript enabled if using the web interface
  • • Administrative credentials for target firewalls

SonicOS API: If SonicOS API is disabled, the tool will attempt to temporarily enable it via SSH (if SSH management is available). The API is automatically disabled after operations complete.

Operation Types & Features

Analysis Mode

Comprehensive assessment without making changes:

  • • Runs playbook checks and generates a playbook analysis report
  • • Provides prioritized recommendations and guidance for manual remediation
  • • Tech Support Report and Settings export capabilities

Remediation Mode

Active configuration changes (use with caution):

  • • Forces all users to change password on next login
  • • Sets a temporary password for the user (either randomized or user-provided)
  • • Resets TOTP binding for all users

Important: Remediation operations modify firewall configurations. Always verify settings and have backups before proceeding with configuration changes.

CSV File Format

The CSV file must contain specific columns with proper formatting. Use the template download feature for the correct format.

Column Name Description Example
target_fw IP address or hostname (optional :port) 192.168.1.1 or firewall.company.com:4443
admin_user Administrative username admin
admin_password Administrative password MySecureP@ssw0rd!
target_ssh_mgmt_port SSH port (1-65535, 0=disable) 22 or 2222
temporary_password Custom temp password (empty=random) TempPass123! or ""
unbind_totp Unbind TOTP authentication true or false
force_password_change Force password change on next login true or false
randomize_temp_password Generate random password automatically true or false

Example CSV Content

target_fw,admin_user,admin_password,target_ssh_mgmt_port,temporary_password,unbind_totp,force_password_change,randomize_temp_password

192.168.1.2:4443,admin,SecureP@ss,2222,"",false,true,true

Security & Privacy

Data Protection

  • • All operations performed client-side, communicating only with the configured target
  • • No data/communication sent to external servers except the configured target

Password Complexity Requirements

  • • Minimum 12 characters
  • • Contains uppercase and lowercase letters
  • • Includes numbers and special characters

Step-by-Step Workflow

Single Firewall Workflow

  1. 1 Verify network connectivity to target firewall
  2. 2 Navigate to "Single Target" tab
  3. 3 Enter firewall details and credentials
  4. 4 Select desired operations (analysis/remediation)
  5. 5 Execute and monitor progress
  6. 6 Review results and download reports

Multiple Firewall/Batch Operations Workflow

  1. 1 Copy the sample CSV content above, or refer to the included sample CSV.
  2. 2 Populate CSV with firewall information
  3. 3 Validate CSV format and connectivity
  4. 4 Upload CSV file to the tool
  5. 5 Review detected targets and configuration
  6. 6 Execute batch processing and monitor progress
  7. 7 Download the playbook analysis reports
