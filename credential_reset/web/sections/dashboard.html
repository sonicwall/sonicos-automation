Welcome to the SonicWall Credential Reset Tool

This web-based interface allows you to easily force password resets in bulk, apply a new temporary password, reset TOTP bindings in bulk, and perform a remediation playbook analysis on SonicWall firewalls. Analyze configurations, reset user credentials, and generate detailed reports with action items based on the current configuration.
