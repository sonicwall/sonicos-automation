Help & Documentation

Getting Started

This tool provides an intuitive web interface for the SonicWall Credential Reset functionality. You can either process a single firewall or multiple firewalls using a CSV file.

CSV Format

The CSV file should contain the following columns:

  • target_fw - IP address or hostname of the firewall
  • admin_user - Admin username
  • admin_password - Admin password
  • target_ssh_mgmt_port - SSH management port (default: 22)
  • temporary_password - Temporary password to set (leave empty for random)
  • unbind_totp - Whether to unbind TOTP (true/false)
  • force_password_change - Whether to force password change (true/false)
  • randomize_temp_password - Whether to generate random password (true/false)

Security Features

  • All operations are performed client-side - no data is sent to external servers
  • Credentials are not stored after the session ends
  • Passwords meet complexity requirements automatically
  • Comprehensive analysis based on the Essential Credential Reset and Remediation Playbook KB articles
